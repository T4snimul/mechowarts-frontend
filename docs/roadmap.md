# Roadmap

This document captures the planned direction for Mechowarts.

## Current status

- Home page is implemented with a hero section and a global layout.
- Shared header and footer components are in place.
- Dashboard route shell is scaffolded.

## Short-term goals

- Add authentication and `/auth` pages.
- Build the core dashboard experience.
- Add course listings and progress tracking.
- Implement a student study resources section.
- Add state management with Zustand for shared UI state.

## Mid-term goals

- Add analytics and progress insights.
- Support notifications and announcements.
- Add community and collaboration sections.
- Improve accessibility and mobile workflows.

## Long-term goals

- Add offline-capable features.
- Add role-based access and profile settings.
- Integrate with external student services or data sources.
- Add end-to-end and component testing coverage.
